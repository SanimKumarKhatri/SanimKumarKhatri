## 🧭 A few projects to start with

| Project | What it is |
|---|---|
| [`rl-dipole-tuning`](https://github.com/SanimKumarKhatri/rl-dipole-tuning) | RL environment wrapping NEC2 for automated dipole antenna resonant-frequency optimization |
